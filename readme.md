# Order Matching Engine

This respository contains a basic order matching engine implmentation in RUST programming language within `engine` directory and a very basic front end within `app` directory using `Next.js` and `Typescript`.

## Setup

1. Install `rust` and `Node.js`
2. Open a terminal and `cd` into project engine directory and run `cd engine`, then `cargo run`
3. Open another terminal and `cd` into project application directory and first run `yarn` and then `yarn dev`
